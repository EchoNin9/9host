How it works

From editor to edge in a single publish.

  1. 01

    Edit

    Write pages, posts and event listings, upload media and set your brand, all in the app.echo9.net console.

    app.echo9.net
  2. 02

    Compile

    Every page is rendered to plain HTML and CSS. Content is sanitized, and links are root-relative so the site works on any domain.

    index.html · blog/ · events/
  3. 03

    Serve

    The result is an immutable, versioned snapshot served from the CDN edge. No database is queried when someone loads a page.

    published/v12/ → current

Domains & TLS

Live on a subdomain today. On your own domain when you’re ready.

Every site gets an address on echo9.net the moment it’s created. To use your own domain, add one CNAME record at any DNS provider. Certificates are issued and renewed for you.

  1. Included your-site.echo9.net HTTPS from the first publish
  2. Custom domain yourdomain.com CNAME one record, any DNS provider TLS certificate issued and renewed automatically
